# 🔢 Sorting-Programs

Java implementations of four sorting algorithms. Each program sorts an array of **1000 numbers** and measures the execution time.

---

## 📌 Algorithms
- 🫧 Bubble Sort (`BubbleSort.java`)
- 🎯 Selection Sort (`SelectionSort.java`)
- 🃏 Insertion Sort (`InsertionSort.java`)
- ✂️ Merge Sort (`MergeSort.java`)

---

## ⚙️ What each program does
- Uses an array of 1000 numbers, filled in the code
- Runs three cases:
  - ✅ **Best case:** array already sorted
  - 🔀 **Average case:** array in random order
  - ⚠️ **Worst case:** array in reverse order
- Prints the total elements, execution time in nanoseconds and milliseconds, and the sorted array

---

## ⏱️ Time Complexity

| Algorithm | Best | Average | Worst |
|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |

---

## ▶️ How to Run
Compile and run each file separately:

    javac BubbleSort.java
    java BubbleSort

Do the same for the other three files.
